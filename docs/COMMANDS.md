## How to add a command

Drop a file into `src/plugins/<category>/` exporting an object (or array of objects):

```js
export default {
  name: 'mycommand',
  aliases: ['mc'],
  category: 'tools',
  description: 'What it does, in one line',
  usage: '.mycommand <arg>',
  cooldown: 3,
  async execute(ctx) {
    return ctx.reply(`Hello ${ctx.pushName}`)
  }
}
```

Restart (or `.reload` as owner) — the registry picks it up, validates it, and refuses duplicates.
